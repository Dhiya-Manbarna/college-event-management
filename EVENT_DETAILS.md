# Event Details Feature

This feature describes the information students should be able to find for each college event.

## Event Information
- **Event name:** Annual Cultural Fest
- **Date:** 15 February
- **Venue:** College Auditorium
- **Organiser:** Student Event Committee
- **Description:** A college-wide celebration featuring cultural performances, competitions, and student activities.

## Student Checklist
1. Read the event details.
2. Note the date, time, and venue.
3. Contact the organising committee if more information is needed.

## Planned Functionality
- View upcoming events.
- Filter events by category.
- Register interest in an event.
