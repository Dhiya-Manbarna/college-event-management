# college-event-management
A project about managing college events
## About the Project
College Event Management is a simple project created to provide information about different events organised in a college.

## Project Objectives
- To display upcoming college events.
- To provide event dates and venue details.
- To share event schedules.
- To help students stay updated about college activities.

## Types of Events
1. Cultural Events
2. Sports Events
3. Technical Events
4. Workshops
5. College Festivals

## Technologies Used
- HTML
- CSS
- JavaScript

## Author
Created as part of the Web Integration and Application assignment.
## Benefits for Students
- Easy access to event information.
- Better awareness of college activities.
- Information about upcoming competitions.
- Improved student participation.

## Event Planning Details
